## 🔴 Critical (6)

1. **ADB SMS allowlist bypass** — empty `ALLOWED_PHONE_NUMBERS` skips the guard entirely, allows SMS to any number
2. **Plugin sandbox is bypassable** — `exec` with restricted globals is not a real sandbox; `__subclasses__`, `ctypes` escape it
3. **SSRF bypass via IPv6-mapped IPv4** — `::ffff:192.168.1.1` passes through the private-IP guard due to swallowed `TypeError`
4. **Thread-unsafe hard-cap date reset in `_track_usage`** — concurrent calls race past the TOCTOU reset, double-fire Telegram alert or miss blocking
5. **GoalRunner executor deadlock risk** — two semaphores across manual and autonomy paths can deadlock on cross-path tool calls
6. **LLM output triggers arbitrary tool execution in autonomy mode** — medium-risk steps (score 4–6) auto-confirm after 5s countdown with no user in loop; injectable via web scraping/OCR

## 🟠 Major (19)

7. **`ask_stream` finally block double-persists turns** — exception between `add_turn` and `committed=True` causes duplicate history entries
8. **`summary_last_trigger_count` never resets on session clear** — stale trigger count suppresses re-summarization for up to 3 turns after `reset_context`
9. **GoalRunner executor shutdown deadlock** — `shutdown(wait=False)` abandons mid-execution threads that may hold internal locks
10. **Emergency stop path traversal** — `EMERGENCY_STOP_FILE` not validated; LLM-controlled `.env` write can redirect it anywhere
11. **MCP HTTP connector SSRF logic fragile** — DNS timeout silently sets `resolved_private=False`; double-negative logic is misconfiguration-prone
12. **Session persistence fails silently on cross-device temp file** — cross-device `OSError` swallowed, session not saved, caller unaware
13. **`sync_all_pending` blocks every `ask_stream` call** — synchronous mem0 network op on the hot path before LLM call
14. **Background summarizer submits duplicate jobs** — no cooldown after summary completes; re-triggers after 3 new turns immediately
15. **Ollama health check uses hardcoded `/api/tags` path** — fails for vLLM/LM Studio backends, triggers unnecessary restart attempts
16. **CLI PIN lock file path traversal** — `Path.home() / CLIP_IN_LOCK_FILE.lstrip(".")` breaks for absolute paths; home dir silently ignored
17. **Autonomy loop overwrites cancelled goals back to `running`** — cancel checked post-execution, not pre-execution inside lock
18. **No rate limiting on LLM calls from autonomy loop** — `step_delay_seconds` defaults to `0.0`, autonomy can exhaust API keys rapidly
19. **ChromaDB corruption has no recovery path** — backup exists but `restore_chromadb()` not implemented; health monitor can't distinguish corruption from slowness
20. **Sensitive API keys logged in dispatcher validation error path** — `scrub_args` called only on success path; `ValidationError` returns raw args including secrets
21. **`requirements.txt` and `requirements.lock` identical** — no real transitive dependency pinning
22. **Docker OmniParser service missing weights/repo** — container starts without running `setup.py`, `vendor/OmniParser` absent
23. **No input validation on goal steps before LLM planning** — no `max_length` on `GoalAddArgs`, no injection detection before planner prompt injection
24. **OmniParser auth token not included in cache key** — stale cached elements returned after server restart with new token
25. **Web scraper "untrusted" tag has no enforcement** — LLM still acts on scraped content; system prompt has no instruction to ignore it as commands
